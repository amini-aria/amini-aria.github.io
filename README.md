# amini-aria.github.io — Labradorite redesign (v2)

من محمد آریا امینی هستم. این نسخه‌ی به‌روزرسانی‌شده‌ی سایت شخصی‌ام است — همان هویت لابرادوریت، با یک دور اصلاحات دقیق‌تر: شیشه‌ای‌تر، زنده‌تر، و با جزئیات درست‌تر.

## چیزهایی که در این نسخه عوض شد

- **نام:** انگلیسی همه‌جا «Mohammad Aria Amini» با فاصله؛ فارسی همه‌جا «محمدآریا امینی» بدون فاصله بین محمد و آریا.
- **بخش تماس:** هر راه ارتباطی (ایمیل، تلگرام، اینستاگرام، واتس‌اپ) حالا یک دکمه‌ی کوچک و کلیک‌پذیر است که مستقیم به همون اکانت می‌ره. ایمیل هم به‌صورت متن ساده نمایش داده می‌شه و هم دکمه داره.
  **توجه:** لینک واتس‌اپ فعلاً غیرفعاله (`href="#"`) چون به یک شماره‌ی واقعی با فرمت بین‌المللی نیاز داره (مثلاً `989xxxxxxxxx`). هروقت شماره رو داشتی، در `index.html` و `fa/index.html` جای‌گذاری کن.
- **قاب عکس:** از شش‌ضلعی به یک بلاب ارگانیک تغییر کرد که به‌آرامی فرم عوض می‌کنه، با یک هاله‌ی رنگی چرخان دورش.
- **آیکون ResearchGate:** از نو طراحی شد (یک آیکون شبکه‌ی گره‌ای، هم‌راستا با بقیه‌ی آیکون‌ها).
- **هیرو:** حالا شیشه‌ای (glassmorphism) است، با چند حباب رنگی محو که پشت صفحه به‌آرامی شناورند و پس‌زمینه که به‌آرامی حرکت می‌کنه.
- **بخش‌های خالی رزومه:** به‌جای پاراگراف لورم ایپسوم، حالا یک قاب خط‌چین با جای خالی برای عنوان/سازمان/تاریخ نشون می‌دن — دقیقاً مثل بخش‌های واقعی، فقط خالی.
- **تاریخ آخرین ویرایش:** بالای صفحه‌ی رزومه، به‌صورت خودکار از تاریخ آخرین commit مربوط به همون فایل (از GitHub API) خونده می‌شه؛ در نسخه‌ی فارسی هم شمسی هم میلادی نشون داده می‌شه.
- **رنگ‌بندی:** پررنگ‌تر و شیشه‌ای‌تر شد؛ دیگه به سفید خالی نزدیک نیست.
- **بخش علاقه‌مندی‌ها:** یک پنل رنگی با گرادیان و برش گوشه‌ی الماسی، کاملاً متفاوت از بقیه‌ی بخش‌های رزومه.
- **کارت‌های کتاب/انتشارات:** یک نوار رنگی کناری و ته‌رنگ گرادیانی گرفتن، دیگه کاملاً ساده و سفید نیستن.
- **پی‌دی‌اف‌های دانلودی:** آدرس فقط «تهران، ایران»، لینکدین و لینک سایت شخصی (`amini-aria.github.io`) به‌صورت هایپرلینک، سیویلیکا حذف شد، عنوان شغلی روبه‌روی نام اضافه شد، و پایین صفحه تاریخ آخرین ویرایش به‌صورت خیلی محو درج شده.

## فایل‌های اصلی

```
index.html / fa/index.html               صفحه اصلی
resume/index.html / fa/resume/index.html  صفحه رزومه کامل
publications/index.html / fa/...          صفحه انتشارات
assets/css/style.css                       تمام استایل‌ها
assets/js/app.js                           منو، اسکرول، جلوه‌ی هیرو، تاریخ خودکار
assets/img/hero-lattice.svg, portrait.jpg  تصاویر
assets/files/resume-en.pdf, resume-fa.pdf  رزومه‌های دانلودی
```

## کارهای باقی‌مانده برای خودت

- شماره‌ی واقعی واتس‌اپ رو جایگزین `href="#"` کن (توضیح بالا).
- لینک گیت‌هاب، Google Scholar و ResearchGate هنوز `#` هستند.
- بخش‌های خط‌چین رزومه (تجربه پژوهشی، مقالات، کنفرانس‌ها، پروژه‌های پژوهشی، تدریس، افتخارات، گواهی‌نامه‌ها) رو هر وقت محتوای واقعی آماده شد پر کن.
- تاریخ «آخرین ویرایش» در PDF ثابت است (چون فایل استاتیکه) — هر وقت رزومه رو عوض کردی و خواستی PDF هم به‌روز بشه، بگو تا دوباره بسازمش.

## انتشار روی گیت‌هاب پیجز

بدون تغییر نسبت به قبل — کاملاً استاتیک، بدون build:

**Settings → Pages → Source → "Deploy from a branch"**، شاخه‌ی `main`، پوشه‌ی `/ (root)`.
