# amini-aria.github.io — Labradorite redesign

من محمد آریا امینی هستم. این نسخه بازطراحی کامل سایت شخصی‌ام است: از تم تیره به یک تم روشن و علمی با هویت بصری برگرفته از سنگ لابرادوریت (رنگ‌های آبی تیره، فیروزه‌ای، زمردی و طلایی، با جلوه‌ی رنگین‌کمانی ملایم که با حرکت موس روی کارت هیرو ظاهر می‌شود). ساختار پایه همان سایت قبلی (HTML/CSS/JS ساده، بدون build) حفظ شده، اما تقریباً تمام بخش‌ها بازطراحی شده‌اند.

## نکات مهم

- **پس‌زمینه‌ی هیرو** یک وکتور SVG با الهام از شبکه‌ی بلوری و رگه‌های معدنی است (`assets/img/hero-lattice.svg`)، جایگزین خطوط کانتور نسخه‌ی قبلی.
- **قاب پرتره‌ی شش‌ضلعی** بالای نام، با عکس واقعی (`assets/img/portrait.jpg`).
- **صفحه‌ی رزومه** داخل یک سطح خوانش تقریباً سفید و فشرده قرار دارد و شامل تمام بخش‌های خواسته‌شده است؛ بخش‌هایی که هنوز محتوای واقعی ندارند (تجربه‌ی پژوهشی، مقالات ژورنال/کنفرانس، پروژه‌های پژوهشی، تدریس، افتخارات) با متن Lorem Ipsum به‌عنوان جای‌نگه‌دار مشخص شده‌اند تا چیدمان صفحه حفظ شود؛ در کد با کامنت PLACEHOLDER علامت‌گذاری شده‌اند.
- **دو دکمه‌ی دانلود رزومه** (فارسی و انگلیسی، PDF) بالای صفحه‌ی رزومه اضافه شده. این PDF ها کاملاً جدا از طراحی سایت هستند: سیاه‌وسفید، بدون آیکون یا رنگ، فشرده، مناسب چاپ روی A4 و مناسب سیستم‌های ATS. **توجه:** این PDF ها فقط شامل بخش‌های واقعی رزومه هستند (بدون Lorem Ipsum) چون یک فایل قابل‌ارسال به کارفرما نباید متن جای‌نگه‌دار داشته باشد؛ وقتی بخش‌های خالی سایت رو با محتوای واقعی پر کردی، بگو تا PDF ها رو هم به‌روزرسانی کنم.
- **کپی‌رایت** پایین صفحات کاملاً وسط‌چین شده.

## فایل‌های اصلی

```
index.html / fa/index.html               صفحه اصلی
resume/index.html / fa/resume/index.html  صفحه رزومه کامل
publications/index.html / fa/...          صفحه انتشارات
assets/css/style.css                       تمام استایل‌ها و پالت رنگی
assets/js/app.js                           منو، اسکرول، جلوه‌ی رنگین‌کمانی هیرو
assets/img/hero-lattice.svg                پس‌زمینه‌ی هیرو
assets/img/portrait.jpg                    عکس پروفایل
assets/img/favicon.svg, og-image.jpg       فاویکون و تصویر پیش‌نمایش شبکه‌های اجتماعی
assets/files/resume-en.pdf, resume-fa.pdf  رزومه‌های دانلودی
```

## کارهای باقی‌مانده برای خودت

- در `data`ی سایت، لینک گیت‌هاب، Google Scholar و ResearchGate هنوز `#` هستند.
- بخش‌های Lorem Ipsum رزومه (تجربه پژوهشی، مقالات، کنفرانس‌ها، پروژه‌های پژوهشی، تدریس، افتخارات، گواهی‌نامه‌ها) باید با محتوای واقعی جایگزین شوند.
- برای هر گواهی‌نامه‌ی Coursera، لینک واقعی، عنوان، تاریخ و توضیح را در `resume/index.html` (بخش Licenses & Certifications) وارد کن.

## انتشار روی گیت‌هاب پیجز

سایت کاملاً استاتیک است، بدون build. مثل قبل:

**Settings → Pages → Source → "Deploy from a branch"**، شاخه‌ی `main`، پوشه‌ی `/ (root)`.
